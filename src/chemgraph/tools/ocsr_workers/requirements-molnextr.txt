#       --index-url https://download.pytorch.org/whl/cpu

# The source tree comes from https://github.com/CYF2000127/MolNexTR (not on PyPI).
#
# The torch line is separate because it needs the CPU wheel index. Aurora's GPUs
# are Intel, not CUDA, so every worker runs on CPU.
#
# Needs the MolNexTR source tree as well (build_molnextr.sh clones it to
# ~/opt/MolNexTR); the package is not on PyPI. If `pip install -e` fails the
# worker still runs with PYTHONPATH pointed at the clone.
#
# Weights: molnextr_best.pth (~1.1 GB) from HuggingFace CYF200127/MolNexTR.
#

# against; its torch 2.4/numpy 1.24 combination would run on 3.10 too. Do not
# "modernize" it without re-running the benchmark: the calibration table
# describes these exact interpreters.
